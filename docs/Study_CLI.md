# Study CLI Reference

The `imputebench study` command group provides CLI-first dataset study and post-analysis capabilities.
All outputs are deterministic JSON/CSV/Markdown artifacts.

## Quick Start

```bash
imputebench study --help
imputebench study dataset profile --help
imputebench study temporal stationarity --help
```

## Command Tree

```
imputebench study
├── dataset
│   └── profile          — Build dataset characterization profile
├── missingness
│   └── profile          — Build missingness characterization profile
├── temporal
│   ├── stationarity     — Run ADF/KPSS stationarity tests
│   ├── acf-pacf         — Compute ACF/PACF for sampled series
│   └── arma-order       — Select ARMA orders via IC search
└── results
    └── summarize        — Summarize and rank benchmark results
```

## Study Profiles

| Profile | Description | Data Access |
|---------|-------------|-------------|
| `standard` | Metadata-first summary | metadata_only |
| `full` | Includes array-backed statistics | windowed_array |

## Output Formats

All commands support `--format table` (default, human-readable) and `--format json` (machine-readable).

## Examples

### Dataset Profile

```bash
imputebench study dataset profile \
  --dataset-id london_aq \
  --profile standard \
  --output-dir docs/exports/studies/london_aq/dataset_profile \
  --format json
```

Outputs:
- `dataset/DATASET_PROFILE.json`
- `dataset/DATASET_PROFILE.md`
- `dataset/pollutant_profiles.csv`
- `STUDY_MANIFEST.json`

### Missingness Profile

```bash
imputebench study missingness profile \
  --dataset-id london_aq \
  --include-arrays \
  --output-dir docs/exports/studies/london_aq/missingness_profile
```

Outputs:
- `missingness/MISSINGNESS_PROFILE.json`
- `missingness/MISSINGNESS_PROFILE.md`
- `missingness/mask_bank_summary.csv`

### Stationarity Tests

```bash
imputebench study temporal stationarity \
  --dataset-id london_aq \
  --tests adf,kpss \
  --alpha 0.05 \
  --max-d 1 \
  --sample-policy all \
  --output-dir docs/exports/studies/london_aq/temporal_stationarity
```

Outputs:
- `temporal/STATIONARITY_REPORT.json`
- `temporal/stationarity_by_series.csv`

### ACF/PACF Analysis

```bash
imputebench study temporal acf-pacf \
  --dataset-id london_aq \
  --max-lag 48 \
  --sample-columns 50 \
  --output-dir docs/exports/studies/london_aq/acf_pacf
```

Outputs:
- `temporal/ACF_PACF_REPORT.json`

### ARMA Order Selection

```bash
imputebench study temporal arma-order \
  --dataset-id london_aq \
  --p-max 5 \
  --q-max 5 \
  --criterion bic \
  --max-d 1 \
  --output-dir docs/exports/studies/london_aq/arma_order
```

Outputs:
- `arma/ARMA_ORDER_SELECTION.json`
- `arma/ARMA_ORDER_SELECTION.md`
- `arma/arma_order_by_series.csv`

#### Performance Options (patch 04)

The ARMA order selection command supports parallelisation, early stopping, and
per-fit timeouts to reduce runtime from hours to minutes for large datasets.

| Option | Default | Description |
|---|---|---|
| `--n-jobs INTEGER` | `1` | Series-level parallel workers. Use `-1` for all cores. |
| `--progress / --no-progress` | `--progress` | Show progress bar (requires tqdm; silent fallback if unavailable). |
| `--timeout-seconds INTEGER` | `30` | Per-fit timeout in seconds. Use `0` to disable. |
| `--early-stopping / --no-early-stopping` | `--early-stopping` | Stop scanning high-order p/q when the criterion degrades. |
| `--grid-fit-method TEXT` | `auto` | Fast fit method for grid search (`auto`, `css`, `statespace`, …). |
| `--final-refit-method TEXT` | `statespace` | Method used to refit the winning order. |

##### Examples

Sequential deterministic debug:
```bash
python -m imputebench study temporal arma-order \
  --dataset-id london_aq \

  --criterion bic \
  --n-jobs 1 --no-progress \

```

Optimised practical run:

python -m imputebench study temporal arma-order \

#### Caveats

- Fast grid fitting (e.g., CSS) is used for candidate pruning. The final winner
  is refit with `statespace` when supported.
- Early stopping may skip high-order candidates after criterion degradation. Use
  `--no-early-stopping` for full-grid evaluation.
- Timeouts exclude pathological fits and are reported explicitly in the output.
- The plugin (`plugins/arma/order_selection.py`) delegates to the same shared
  core as the study service, avoiding duplicated logic.

## Stationarity Policy

The stationarity tests apply a two-test policy:

| ADF | KPSS | Verdict | Action |
|-----|------|---------|--------|
| Rejects unit root | Does not reject stationarity | stationary | d=0 |
| Mixed | Mixed | mixed | Config-dependent |
| Fails to reject | Rejects stationarity | non-stationary | Difference up to max_d |

## ARMA Order Selection

Order selection uses IC-based search:

1. Determine `d` via stationarity tests
2. Search `p ∈ [0, p_max]`, `q ∈ [0, q_max]` (skip p=q=0)
3. Select best by AIC or BIC
4. Fall back to preset orders on failure
