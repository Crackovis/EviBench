# Spatial Missingness Protocol — LondonAQ Spatio-Temporal Lane

## Purpose

Temporal-only benchmarks mainly test whether a model reconstructs hidden values from temporal context. The spatio-temporal lane must also test whether a model uses spatial context.

Therefore, the lane uses two categories of missingness:

1. parity masks shared with temporal benchmarking;
2. spatial-aware masks that stress graph reasoning.

## Category A — Temporal parity masks

These reuse the existing controlled missingness families:

```text
MCAR
MAR
MNAR
```

with rates:

```text
0.1
0.3
0.5
```

Purpose:

- compare ST models to temporal models under the same hidden support;
- preserve continuity with the temporal benchmark;
- avoid changing everything at once.

## Category B — Spatial-aware masks

### `spatial_block`

Masks contiguous spatial regions.

Recommended first configuration:

```text
block_shape = rectangular grid block
rates = 0.3, 0.5
phase = test
observed_only = true
```

Purpose:

- test spatial interpolation from neighboring regions;
- expose failure cases where temporal-only models have limited external evidence.

### `sensor_dropout`

Masks full node trajectories or large portions of node trajectories.

Recommended first configuration:

```text
dropout_unit = node
rates = 0.3, 0.5
phase = test
observed_only = true
```

Purpose:

- simulate sensor outage;
- evaluate whether graph neighbors help reconstruct missing stations.

### `node_holdout`

Holds out selected nodes as kriging-style targets.

Recommended first configuration:

```text
holdout_unit = node
rates = 0.3, 0.5
phase = test
observed_only = true
```

Purpose:

- create a fair evaluation condition for IGNNK;
- simulate unsampled or unavailable locations.

## Recommended official tiers

### Tier A — Minimum viable ST evidence

```text
MCAR 0.3
MAR 0.3
MNAR 0.3
spatial_block 0.3
sensor_dropout 0.3
node_holdout 0.3
```

This tier is the fastest defensible ST execution target.

### Tier B — Full ST benchmark

```text
MCAR/MAR/MNAR × 0.1/0.3/0.5
spatial_block × 0.3/0.5
sensor_dropout × 0.3/0.5
node_holdout × 0.3/0.5
```

Total:

```text
15 recipes
```

## Shared rules

| Rule | Value |
|---|---|
| Split mode | temporal |
| Test masks | shared benchmark mask banks |
| Validation policy | shared validation selection |
| Metrics | MAE, RMSE |
| Metric scope | global + pollutant + node |
| Spatial metric scope | optional region/node-group summaries |
| Mask realizations | 5 |
| Seed base | 1729 |
| Observed-only | true |

## Claim limits

Spatial-aware masks support claims about spatial robustness only when:

- the same mask bank is reused across ST models;
- temporal baselines are evaluated on comparable hidden support;
- graph policy is recorded;
- node mapping is stable;
- result artifacts include graph fingerprint.
