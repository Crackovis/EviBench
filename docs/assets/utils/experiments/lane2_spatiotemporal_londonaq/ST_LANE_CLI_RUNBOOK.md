# ST Lane CLI Runbook

## 1. Preflight
```powershell
imputebench st preflight --dataset-id london_aq --graph-id <graph_id> --graph-output-dir data/benchmark_graphs/official_londonaq
```

## 2. Graph build
```powershell
imputebench st graph build --dataset-id london_aq --policy grid_4n_v1 --output-dir data/benchmark_graphs/official_londonaq
```

## 3. Tensor inspect
```powershell
imputebench st tensor inspect --dataset-id london_aq --graph-id <graph_id> --output-dir data/benchmark_graphs/official_londonaq
```

## 4. Mask bank creation
```powershell
imputebench st mask-bank create --dataset-id london_aq --family mcar --rate 0.3 --realizations 5 --graph-id <graph_id> --graph-output-dir data/benchmark_graphs/official_londonaq --output-dir data/benchmark_mask_banks/official_londonaq/st/mcar_03
```

## 5. Smoke plan generation
```powershell
imputebench st plan create --recipe official_londonaq_st_benchmark --tier smoke --dataset-id london_aq --graph-id <graph_id> --graph-output-dir data/benchmark_graphs/official_londonaq --algorithm stgcn --mask-bank mcar=<mcar_bank_id>
```

## 6. Smoke execution
```powershell
imputebench st run execute --run-id <smoke_run_id>
```

## 7. Smoke gate
```powershell
imputebench st gate --profile smoke_ready --output-dir data/exports/thesis/chapter06/06_st_gates --graph-output-dir data/benchmark_graphs/official_londonaq
```

## 8. Tier A mask bank creation
Repeat mask-bank creation for `mar`, `mnar`, `spatial_block`, `sensor_dropout`, `node_holdout`.

## 9. Tier A plan generation
```powershell
imputebench st plan create --recipe official_londonaq_st_benchmark --tier A --dataset-id london_aq --graph-id <graph_id> --graph-output-dir data/benchmark_graphs/official_londonaq --mask-bank mcar=<mcar_bank_id> --mask-bank mar=<mar_bank_id> --mask-bank mnar=<mnar_bank_id> --mask-bank spatial_block=<spatial_block_bank_id> --mask-bank sensor_dropout=<sensor_dropout_bank_id> --mask-bank node_holdout=<node_holdout_bank_id>
```

## 10. Tier A execution
```powershell
imputebench st run execute --run-id <tier_a_run_id>
```

## 11. Comparison export
```powershell
imputebench st compare --lot within_st --output-dir data/exports/thesis/chapter06/04_st_comparisons
```

## 12. Evidence export
```powershell
imputebench st evidence export --chapter 06 --output-dir data/exports/thesis/chapter06 --graph-output-dir data/benchmark_graphs/official_londonaq --dataset-id london_aq
```

## 13. Gate reports
```powershell
imputebench st gate --profile thesis_ready --output-dir data/exports/thesis/chapter06/06_st_gates --graph-output-dir data/benchmark_graphs/official_londonaq
```

## 14. Mddocx mirror
```powershell
imputebench st evidence mirror --source data/exports/thesis/chapter06 --thesis-root Scopes/EvalBatch3[2025-2026]/Revisions/Thesis/v0.2
```

## 15. Troubleshooting
- If graph loading fails in official mode, rebuild the graph asset and rerun preflight.
- If `node_holdout` is blocked, regenerate the mask bank with `--graph-id`.
- If thesis gate fails, inspect Chapter 06 storyboards and gate reports before claiming results.
