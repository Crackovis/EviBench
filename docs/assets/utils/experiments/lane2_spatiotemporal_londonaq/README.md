# Lane 2 — Spatio-Temporal LondonAQ Design Pack

**Status**: implemented and executable — the ST lane is fully orchestrated by the CLI (`imputebench st …`), and the official Tier-A campaign has been executed and certified.  
**Recipe book**: `official_londonaq_st_benchmark`  
**Machine-readable registry**: [`recipes/`](recipes/README.md) (CLI-materialized, checksummed)

> 📖 **For the full CLI-first philosophy, lifecycle, command reference, certification semantics, and developer replication pattern, see:**
> [`docs/ST_Experiment_CLI_Philosophy.md`](../../../../ST_Experiment_CLI_Philosophy.md)

The markdown files in this folder are the *design pack*: they document intent, protocols, and claim limits. The executable truth is the CLI plus the services behind it; the `recipes/` registry is the deterministic bridge between the two.

## Purpose

This lane extends the LondonAQ benchmark from temporal-only imputation to spatio-temporal imputation.

The objective is not to introduce a new model architecture. The objective is to provide a controlled, reproducible spatio-temporal benchmark that can evaluate whether graph-aware models improve imputation when spatial structure is informative.

## Dataset assumptions

| Property | Value |
|---|---|
| Dataset | synthetic LondonAQ |
| Spatial structure | 14 × 10 regular grid |
| Spatial nodes | 140 |
| Timestamps | 600 |
| Temporal resolution | 1 minute |
| Pollutants / features | 4 |
| Natural missingness | none |
| Evaluation missingness | artificial masks |

## Tensor view

Temporal lane input can be interpreted as:

```text
X_temporal = [T, rows, cols, features]
```

Spatio-temporal lane should expose a graph tensor view:

```text
X_graph = [T, N, F]
N = rows × cols = 140
F = pollutants = 4
```

A stable node-index mapping must be recorded so that every graph, mask, prediction, and result uses the same station/grid-cell identity.

## Official model set

| Model | Role | Reason |
|---|---|---|
| STGCN | graph-temporal baseline | canonical graph convolution + temporal convolution reference |
| DCRNN | diffusion recurrent baseline | captures diffusion-style spatial dependency and nonlinear temporal dynamics |
| GRIN | imputation-native graph model | directly aligned with multivariate time-series imputation on sensor networks |
| IGNNK | kriging / node-holdout model | directly aligned with recovering signals at unsampled or dropped sensors |

## Claim limits

Allowed claims:

- The lane evaluates representative graph-based spatio-temporal imputation approaches.
- It compares temporal-only and graph-aware imputation under controlled mask conditions.
- It tests whether spatial structure helps under spatially structured information loss.

Not allowed:

- Claiming a new spatio-temporal architecture.
- Claiming real-world sensor deployment performance from synthetic data alone.
- Claiming graph superiority without graph-policy sensitivity checks.
- Comparing ST and temporal runs when masks, splits, or hidden support differ.

## Current implementation status

The lane is implemented end to end and driven by the `imputebench st` command group:

- graph asset model, fingerprinting, and persistence (`st graph build/inspect/list`);
- graph-compatible dataset loading and tensor adapter (`st tensor inspect`);
- graph-aware mask banks with shared realizations (`st mask-bank create`);
- ST recipe book validation and materialized machine-readable registry (`st recipe …`, see [`recipes/`](recipes/README.md));
- plan generation and orchestrated execution (`st plan create`, `st experiment run`);
- spatio-temporal algorithm plugin contracts with corrected variants (stgcn → stconv_v1, grin → mpgru_v1, ignnk → dgc_kriging_v1, dcrnn → dcgru_reconstruction_v1);
- evidence export, readiness gates, and scientific gates (`st evidence …`, `st gate`, `st scientific gate report`);
- official Tier-A campaign certification (`st experiment certify-official`) — 24 ExperimentRun containers (4 algorithms × 6 mask families) carrying 120 evaluation cells (× 5 realizations), certified complete in the canonical report under `docs/exports/thesis/chapter06/00_st_recipe_book/`.
