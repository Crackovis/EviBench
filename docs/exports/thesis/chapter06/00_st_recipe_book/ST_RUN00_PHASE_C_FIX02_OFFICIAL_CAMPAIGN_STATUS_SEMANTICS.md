# ST-RUN00-PHASE-C-FIX02

## Verdict

`LAUNCH_READY_WITH_CORRECT_OFFICIAL_CAMPAIGN_STATUS`

## Problem repaired

SCI-FIX08 and SCI-FIX09 evidence alignment was already clean, but SCI-FIX09 still upgraded pre-launch evidence to official campaign evidence.

Incorrect pre-fix semantics:

- `official_campaign_launched = true`
- `official_tier_a_campaign_complete = true`
- `official_tier_a_ready_for_thesis = true`

while launch-preparation and reconciliation artifacts still correctly said the user had not yet launched the official 120-run Phase C campaign.

## Root cause

`_compute_official_tier_a_campaign_status()` in `imputebench/services/spatiotemporal/st_scientific_gate_service.py` used loose completed-result inventory inference. That logic was too permissive and could treat generic ST result inventory as if it were proof of the official Tier A campaign.

## Semantic rule now enforced

Official Tier A status now comes only from explicit official campaign evidence:

- `docs/exports/thesis/chapter06/00_st_recipe_book/ST_RUN00_PHASE_C_TIER_A_OFFICIAL_REPORT.json`
- `docs/exports/thesis/chapter06/00_st_recipe_book/ST_RUN00_PHASE_C_OFFICIAL_STATUS.json`
- `docs/exports/thesis/chapter06/00_st_recipe_book/ST_RUN00_PHASE_C_CAMPAIGN_MANIFEST.json`

If none of these files exists:

- `official_campaign_launched = false`
- `official_tier_a_campaign_complete = false`
- `official_tier_a_ready_for_thesis = false`

A dry-run plan is not launch evidence. Calibration evidence is not official campaign evidence. Generic completed results are not enough.

## Current canonical state

From `09_scientific_gate/SCIENTIFIC_GATE_REPORT.json`:

- `global_status = passed`
- `scientific_ready = true`
- `calibration_scientific_ready = true`
- `official_campaign_launched = false`
- `official_tier_a_campaign_complete = false`
- `official_tier_a_ready_for_thesis = false`
- `official_campaign_status_source = null`
- `official_campaign_status_blockers = ["official_campaign_status_report_missing"]`

Interpretation:

- calibration/infrastructure evidence is ready;
- official Tier A benchmark claims remain blocked;
- thesis-ready Tier A completion has not been proven yet.

## Launch-preparation status

Launch-preparation remains pre-launch and still says:

- `decision = LAUNCH_READY`
- `official_campaign_launched = false`
- final launch command present

Tier A dry-run plan size confirmed: `120` rows.

Final launch command remains valid and unchanged:

```text
python -m imputebench st experiment run --tier a --dataset-id london_aq --graph-policy correlation_train_v1 --realizations 5 --epochs 100 --early-stopping --patience 15 --min-delta 0.0001 --min-epochs-before-early-stop 50 --checkpoint-policy best_validation_loss --validation-policy masked_validation_support --skip-completed --progress text --event-log data/logs/phase_c_v2_events.jsonl --progress-file data/logs/phase_c_v2_progress.json
```

## Renderer and claim-scope updates

SCI-FIX09 Markdown now keeps the semantic distinction explicit:

- calibration-level claims may be listed as allowed;
- official Tier A benchmark claims stay blocked before official campaign completion;
- next actions now tell the user to launch the official campaign manually and materialize an explicit official status report before claim upgrade.

## Tests

Covered by:

- `tests/spatiotemporal/test_phase_c_official_campaign_status_semantics.py`
- `tests/spatiotemporal/test_st_scientific_gate.py`
- `tests/spatiotemporal/test_phase_c_report_reconciliation.py`
- `tests/spatiotemporal/test_phase_c_canonical_report_alignment.py`

The test set verifies:

- dry-run plan does not imply launch;
- calibration readiness does not imply official completion;
- official report completion requires `120/120` completed, `0` failed, and exact plan match;
- Markdown and JSON remain aligned on official campaign semantics.

## Explicit confirmation

No official 120-run Phase C campaign was launched during FIX02.

This repair changed semantics, report rendering, tests, and canonical exports only.
