# Thesis Evidence Map — DL Lifecycle (dl_curriculum_v1)

Maps the ImputeBench DL lifecycle (FT-DL35–43) to thesis claims and required evidence.

## Recommended thesis placement

Chapter 04 / Experimental Methodology:

```
4.x   Experimental protocol for temporal deep-learning imputation
4.x.1 Benchmark contracts and held-out test masks
4.x.2 Curriculum-to-target training schedule
4.x.3 Stable validation surface for checkpoint selection
4.x.4 Best training-loop evidence and checkpoint provenance
4.x.5 Comparison and claim limitations
```

## Allowed thesis claim

> The DL models were evaluated under benchmark contracts using independent test realizations.
> Their selected checkpoints were chosen from a controlled multi-loop training lifecycle,
> where training difficulty could progress toward the benchmark target while validation selection
> remained stable and comparable.

## Claims that must NOT be made

- The curriculum schedule is universally optimal for all DL architectures.
- Later training loops always produce lower test error.
- The selected best loop proves model convergence in the strict mathematical sense.

## Evidence table

| Thesis claim | Required EviBench evidence | Evidence field |
|---|---|---|
| Test benchmark was independent | Benchmark contract ID, mask bank ID, realization IDs | `benchmark_contract_id`, `benchmark_mask_bank_id`, `benchmark_realization_ids` |
| Validation selection was stable | Missingness protocol validation rates match target; loop schedule validation rates fixed | `missingness_protocol.validation.rates`, `training_loop_policy.loop_schedule[*].validation_rates` |
| Training used curriculum schedule | Training loop schedule rows in protocol | `missingness_protocol.training_loop_policy.loop_schedule` |
| Loop schedule mode is custom | `loop_schedule_mode` | `missingness_protocol.training_loop_policy.loop_schedule_mode == "custom"` |
| Selected checkpoint is traceable | Selected checkpoint path | `selected_checkpoint_path` |
| Best loop selection is traceable | Best training loop summary | `runtime_summary_payload.best_training_loop` |
| Loop execution occurred | Loop trace path | `training_loop_trace_path` |
| Comparison is fair | Comparison Studio compatibility + shared benchmark parity | Comparison Studio `reportable` status |
| Thesis claim is safe | Evidence gate complete and no caveats blocking | `best_training_loop.evidence_status == "complete"` |

## Caveats to state in thesis text

- The curriculum-to-target schedule is an experimental training protocol, not a universal claim
  of training optimality. The schedule is deterministic and shared across all algorithms to ensure
  comparability, not to optimize any single algorithm.
- A selected loop at index 0 may indicate that target difficulty was already reachable from the
  lowest training rate, or that later loops did not improve validation performance. This is a valid
  outcome, not a protocol failure.
- Loops with equal selection metric values should be treated as tie/no-improvement, not regression.
- The LondonAQ dataset is synthetic. Conclusions must be worded as evidence from controlled
  synthetic experiments, not as generalizable real-world claims.
- Results from plans created before `dl_lifecycle_policy_version = dl_curriculum_v1` should be
  marked as pre-curriculum baselines, not curriculum-lifecycle evidence.
