# Study Assets — Dataset Study & ARMA Diagnostics

This directory contains exported study artifacts produced by `imputebench study` commands.

## Purpose

The study subsystem provides CLI-first dataset characterization, missingness profiling,
temporal diagnostics, and ARMA order selection. Outputs are deterministic JSON/CSV/Markdown
artifacts suitable for scientific reporting and reproducibility.

## Lane Structure

| Lane | Command | Output |
|------|---------|--------|
| Dataset | `study dataset profile` | DATASET_PROFILE.json, pollutant_profiles.csv |
| Missingness | `study missingness profile` | MISSINGNESS_PROFILE.json, mask_bank_summary.csv |
| Stationarity | `study temporal stationarity` | STATIONARITY_REPORT.json, stationarity_by_series.csv |
| ACF/PACF | `study temporal acf-pacf` | ACF_PACF_REPORT.json |
| ARMA Order | `study temporal arma-order` | ARMA_ORDER_SELECTION.json, arma_order_by_series.csv |
| Results | `study results summarize` | RESULT_SUMMARY.json, ranking.csv |

## Output Root Convention

```
docs/exports/studies/<dataset_slug>/<study_kind>/
```

Each directory contains a `STUDY_MANIFEST.json` with provenance and fingerprint.

## Relation to Thesis

Thesis commands (`imputebench thesis ...`) remain separate and may later wrap
generic study services. Study outputs are thesis-independent and product-facing.

## ARMA Plugin

The ARMA plugin (`plugins/arma/`) provides classical ARMA/ARIMA imputation.
See [ARMA Imputer Design](../../../algorithm_design/arma_imputer.md) for details.

## Operator Workflow

```bash
# 1. Characterize dataset
imputebench study dataset profile --dataset-id london_aq --output-dir ./studies/dataset

# 2. Profile missingness
imputebench study missingness profile --dataset-id london_aq --output-dir ./studies/missingness

# 3. Run stationarity tests
imputebench study temporal stationarity --dataset-id london_aq --output-dir ./studies/stationarity

# 4. Select ARMA orders
imputebench study temporal arma-order --dataset-id london_aq --output-dir ./studies/arma

# 5. Register and validate ARMA plugin
imputebench plugin validate arma
imputebench plugin register arma

# 6. Analyze results
imputebench study results summarize --dataset-id london_aq --output-dir ./studies/results
```
