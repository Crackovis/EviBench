## 5. Early Stopping Policy

| Parameter | Value |
|-----------|-------|
| `early_stopping` | `true` |
| `patience` | 15 |
| `min_delta` | 0.0001 |
| `min_epochs_before_early_stop` | 50 |
| `checkpoint_policy` | `best_validation_loss` |

**Warm-up rationale:** IGNNK validation loss drops from ~13,175 to ~1,801 over the first
50 epochs. Without a warm-up window, early stopping would fire prematurely on the initial
unstable plateau. Setting `min_epochs_before_early_stop=50` matches the calibration
horizon and ensures all meaningful convergence occurs before patience counting begins.

**Implementation:** `STEarlyStoppingState` in `plugins/_st_graph_validation.py` with
helpers `make_st_early_stopping`, `st_early_stopping_step`, `restore_best_checkpoint`.
All four corrected variant training loops (`_fit_stconv`, `_fit_mpgru`, `_fit_dgc`,
`_fit_dcgru`) are wired to these helpers.

## 8. Resume and Skip-Completed

`--skip-completed` checks for an existing `COMPLETED` result before executing each run.
If found, the run is logged as `skipped` and the campaign continues.

The JSONL event log is opened in append mode; restarts accumulate events without
overwriting prior session entries.

**Implementation:** `imputebench/services/spatiotemporal/st_experiment_orchestrator.py`
