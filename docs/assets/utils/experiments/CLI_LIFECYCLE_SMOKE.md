# CLI Lifecycle Smoke Protocol

Phase 14 end-to-end verification for the DL evidence lifecycle CLI chain.

## Purpose

This protocol proves the full CLI command path works against a real lifecycle run:

```
service graph bootstrap → repository access → run/result resolution
→ file export → manifest completeness → gate status → audit matrix generation
```

## Precondition

Use one real lifecycle run created from the rebased official DL recipe book.

Preferred:

- algorithm: SAITS
- family: MCAR
- target rate: 0.3
- recipe policy: dl_curriculum_v1
- selection surface: stable_validation_surface

## Automated smoke command

```powershell
python scripts/smoke_dl_lifecycle_cli.py \
    --run-id <RUN_ID> \
    --out data/tmp/phase14/smoke \
    --profile thesis_ready
```

## Manual command sequence

From `Interfaces/EviBench`:

```powershell
# Export evidence by run
python scripts/export_dl_lifecycle_evidence.py \
    --run-id <RUN_ID> --out data/tmp/phase14/evidence_by_run --json

# Export trace by run
python scripts/export_training_loop_trace.py \
    --run-id <RUN_ID> --phase train --out data/tmp/phase14/trace_by_run --json

# Gate check
python scripts/check_evidence_gate.py \
    --target-type run --target-id <RUN_ID> \
    --profile thesis_ready --json --output-dir data/tmp/phase14/gate_by_run

# Official audit
python scripts/audit_official_dl_runs.py \
    --recipe-book official_londonaq_dl_benchmark \
    --dataset <DATASET_ID> \
    --families mcar --rates 0.3 \
    --algorithms <ALGORITHM_ID> \
    --include-legacy \
    --out data/tmp/phase14/official_audit --json
```

Then pick a train result ID from `evidence_by_run/result_index.json` and run:

```powershell
python scripts/export_dl_lifecycle_evidence.py \
    --result-id <TRAIN_RESULT_ID> --out data/tmp/phase14/evidence_by_result --json

python scripts/export_training_loop_trace.py \
    --result-id <TRAIN_RESULT_ID> --out data/tmp/phase14/trace_by_result --json
```

## Smoke output structure

```
<out>/
  smoke_report.json
  smoke_report.md
  evidence_by_run/
  evidence_by_result/
  trace_by_run/
  trace_by_result/
  gate/
```

## Required assertions

Both `evidence_by_run/evidence_manifest.json` and `evidence_by_result/evidence_manifest.json` must contain:

```json
{
  "schema_version": "dl_lifecycle_evidence_cli_v1",
  "evidence_status": "complete",
  "run_id": "<RUN_ID>",
  "training_loop_schedule_hash": "...",
  "missingness_lifecycle_id": "...",
  "backend_curriculum_mode": "...",
  "test_realization_count": 5,
  "best_training_loop": {
    "selected_training_loop_index": 0
  }
}
```

Both manifests must agree on `run_id`.

## Stop conditions

Do not delete old benchmark results if any manifest shows:

```
run_id_missing
parent_experiment_run_id_missing
benchmark_contract_id_missing
benchmark_mask_bank_id_missing
training_loop_schedule_hash_missing
selected_training_loop_index_missing
backend_curriculum_mode_missing
test_realization_count_missing_or_zero
legacy_masking_ids_authority_detected on the replacement run
```

{
  "schema_version": "dl_lifecycle_cli_smoke_v1",
  "run_id": "...",
  "train_result_id": "...",
  "checks": [
    {"name": "run_export_manifest_exists", "status": "passed"},
    {"name": "result_export_manifest_exists", "status": "passed"},
    {"name": "run_id_agreement", "status": "passed"},
